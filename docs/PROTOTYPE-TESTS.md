## Повторный запуск автоматической проверки

Сначала `npm ci && npm run build`, затем запустить сервер из корня проекта (см. README). В отдельном терминале:

```sh
CHROME_PATH='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' npm test
```

На другой ОС указать свой `CHROME_PATH` или установить браузер Playwright. `PROTOTYPE_URL` меняет адрес сервера; `SCREENSHOT_DIR` включает сохранение screenshots в существующую папку. Тест создаёт отдельный временный браузерный контекст и не меняет данные вашего обычного профиля.

## Сценарий ручного знакомства

1. Открыть главную, отметить поручение, перейти к математике.
2. Запустить таймер, поставить на паузу; перейти к русскому, запустить его.
3. Вернуться к математике: её время осталось на паузе. Продолжить и сохранить.
4. Внести 25 минут за вчера; увидеть запись в истории и точку на графике.
5. В настройках добавить своё поручение по пятницам; в «Поручениях» проверить подпись и доступность на текущую дату.
6. Добавить занятие с таймером; найти его в разделе «Уроки» рядом с внеклассным чтением.
7. Открыть «Мой мир», купить первую территорию за 60 звёзд. Появятся новая земля и два жителя; повторная покупка недоступна. Переключить остров: там отдельный прогресс. Предпросмотр четвёртого этапа не тратит звёзды.
8. Переключить тёмную/светлую/системную тему в header; сузить окно и повернуть устройство. Открыть профиль через аватар, сохранить имя и выполнить Sign Out. Вернуться в демо и повторить wizard через «Как это работает».
9. Перезагрузить страницу и убедиться, что изменения сохранились.
10. Для возврата к исходной демонстрации: Настройки → Восстановить исходный макет.

## Известные упрощения

- localStorage вместо сервера; нет настоящей авторизации и гарантии конкурентной целостности.
- Редактирование/удаление записей, отчёты по произвольному диапазону, цели пользовательских занятий, исключения расписаний описаны в спецификации, но ещё не реализованы. Табличные альтернативы теперь доступны у stacked/line, а donut имеет числовую легенду.
- Награды и улучшение −14% — иллюстрации; рабочий кошелёк в макете только тратит стартовые демо-звёзды.
- Сессии с переходом через полночь сохраняются за текущую дату; production-поведение описано отдельно.
- Backend, реальные SQL reset/seed, Docker и OpenAI отсутствуют намеренно на этапе макета.
