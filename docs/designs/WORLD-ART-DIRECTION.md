# Арт-дирекшн живых миров — v1

6 октября 2026. Code-native SVG-ассеты для четырёх островов «Всё успею». Заменяют общую перекрашенную геометрию `islandScene` на четыре самостоятельных визуальных языка. Игровая цепочка, цены, темы и список миров не меняются.

## Файлы

| Путь | Что это |
|---|---|
| `prototype/world-art.js` | ES-модуль: чистые функции → строки SVG/HTML. Без DOM, без таймеров, без импорта `worlds.js` (нет цикла импорта) |
| `prototype/world-art.css` | Все анимации `wa-*`, гарантии статики, `prefers-reduced-motion` |
| `prototype/art/emblem-{id}.svg` | 4 эмблемы, 96×96 |
| `prototype/art/upgrade-{id}-{1..4}.svg` | 16 карточек улучшений, 240×140 |
| `prototype/art/scene-{id}-{0,4}.svg` | Статичные снимки старта и полного развития для дизайн-ревью |

Файлы в `prototype/art/` — снимки, сгенерированные из `world-art.js`. Источник правды — модуль; в интерфейсе используйте API, а не файлы.

## API

```js
import { worldEmblem, worldScene, upgradeArtwork } from "./world-art.js";
import "./world-art.css"; // через app.js / esbuild

worldEmblem(id)                       // <svg class="wa-emblem wa-emblem-{id}" viewBox="0 0 96 96">
worldScene(id, level, { motion })     // <div class="island-scene wa-scene wa-{id} [motion-off wa-still]" data-world-art data-level>
                                      //   <svg class="living-island wa-art" viewBox="0 0 960 480" role="img" aria-label="…">
upgradeArtwork(id, index)             // <svg class="wa-upgrade wa-upgrade-{id}" viewBox="0 0 240 140">, index 0..3
```

- `id`: `settlers | bricks | voxel | helpers`; если id неизвестен, используется `settlers`. `level` ограничивается диапазоном 0..4, `index` — 0..3.
- `motion` по умолчанию `true`. Для миниатюр и hero передавайте `motion:false`: обёртка получит `motion-off wa-still`, CSS отключит все анимации, и кадр будет полностью статичным и законченным (дым виден шлейфом, флаги в покое).
- Обёртка задаёт `--island-sky`, `--wa-sky-top`, `--wa-sky-bottom` и `--world-accent`, поэтому при letterbox-вписывании поля продолжают небо.
- `aria-label` сцены: «Мир: N территорий, M жителей. История этапа».

### Инварианты (проверены скриптом для 4 миров × 5 уровней × motion on/off)

- В сцене ровно `2 + 2·level` элементов `.citizen`: 2/4/6/8/10.
- В эмблемах и карточках `.citizen` нет. Фигурки там имеют класс `.wa-figure`, поэтому счётчики smoke-тестов не ломаются.
- `id` внутри `<defs>` уникальны для каждого вызова (счётчик `wa-{kind}-{n}`). Все `url(#…)` ссылаются на объекты того же SVG. Висячих ссылок нет.
- Все SVG валидны для XML-парсера, без `NaN`/`undefined`.
- Нет JS-таймеров. Движение задаётся только CSS-циклами. Классы анимаций имеют префикс `wa-` и не пересекаются с `worlds.css`. Классы из `worlds.css` (`wander`, `mill`, `boat`, `clouds`…) не используются.
- `prefers-reduced-motion: reduce` отключает всё внутри `.wa-scene`, `.wa-art`, `.wa-emblem`, `.wa-upgrade`.

## Концепция: четыре разных языка, одна история

Общими остаются только драматургия этапов и холст 960×480. Проекция, форма, палитра, фактура, жители и даже «туман» у каждого мира свои.

| | Тихая бухта | Брик-сити | Куболесье | Банановый залив |
|---|---|---|---|---|
| Проекция | Боковой многоплановый пейзаж, воздушная перспектива | Изометрия игрушечных пластин на «шиповом море» | Фронтальный срез-диорама кубических колонн (кабинетная проекция) | Фронтальная лагуна, яркий тропический день |
| Форма | Мягкие органические кривые | Чёткие грани, шипы на каждой верхней грани | Пиксельные блоки 24 px, фактуры через `<pattern>` | Округлые, пружинящие формы |
| Палитра | Шалфей, бирюза, терракота, утренний персик | Основные цвета конструктора: красный, жёлтый, синий, зелёный | Трава, земля, камень, аметист, лавандовая дымка | Бирюза, банановый жёлтый, розовый, коралл |

| Животные | Утки с утятами, птицы | Кирпичный щенок, чайки, игрушечные лодочки | Кубическая овечка, пиксельные птицы, прыгающая рыба | Краб, попугаи, морская звезда |

## Правила для расширения

1. **Позиционирование и анимация разделены.** Внешний `<g transform>` размещает объект, внутренний `<g class="wa-…">` двигается. Нельзя ставить SVG-атрибут `transform` на элемент с классом анимации, иначе CSS перезапишет атрибут.
2. **Вращение вокруг шарнира.** Рисуйте вращающуюся группу вокруг (0,0) и добавляйте `pivot(r)` — невидимый круг, который центрирует `fill-box`. Так `transform-origin:center` точно попадает в ось.
3. **Тайминг через переменные.** Задавайте `A(cls, t, o)` → `--wa-t`, `--wa-o`. Пути ходьбы: `actor(x, y, body, {dx, dy, t, d})`. Фаза отрицательная, поэтому жители не стартуют синхронно.
4. **Жители только через `actor()`.** Это единственное место, где появляется `.citizen`. Декоративные фигурки — `figure()`.
5. **Спокойное движение.** Без вспышек и резких стробов: мерцание не чаще ~1 Гц по непрозрачности не ниже 0.35. Огромные объекты не должны мигать.
6. **Статичный кадр должен быть законченным.** Начальное (неанимированное) состояние каждого элемента — красивая поза.
7. **Новые `<defs>` создаются только с `uid()`.**
8. **Проекции не смешиваются.** В Брик-сити используйте `P(i,j,k)`/`box()`, в Куболесье — `vbox()`/`vColumn()` с кратностью 24 (или 16 на дальнем плане) для совпадения фактур.

## Интеграция (для владельца `worlds.js`)

- `islandScene(id, level, {motion})` → `worldScene(id, level, {motion})`. Флаг `preview` больше не нужен: обёртка остаётся `.island-scene`, и все существующие селекторы и медиазапросы `worlds.css` продолжают работать.
- Иконка в `worldSwitcher`: `worldEmblem(w.id)` в `.world-symbol`, контейнеру 38×44 нужен `width/height:100%` (уже есть в `.wa-emblem`).
- `.upgrade-art`: `upgradeArtwork(w.id, i)` вместо мини-сцены. SVG использует `preserveAspectRatio="xMidYMid slice"` и заполняет блок 145 px без полей. Задайте `.upgrade-art .wa-upgrade{height:145px}`.
- Тёмная тема: текущий фильтр `.island-scene` в `worlds.css` подходит. Для карточек лучше `filter: saturate(.9) brightness(.86)`.
- Вес строки сцены: 16–40 KB (бухта, залив), 25–72 KB (Брик-сити), 69–87 KB (Куболесье: дальний план и пиксельный туман). Для одного активного мира и четырёх статичных карточек это допустимо. При необходимости можно кешировать строку по `id+level+motion`, но затем нужно заново уникализировать `id` (или рендерить заново).

## Проверка

Визуальная QA выполнена рендером в Chrome через Playwright: все уровни статично и кадр анимации через 3,3 с. Структурная проверка: счётчик жителей, уникальность `id`, ссылки `url(#)`, XML-парсинг. Браузерный интеграционный smoke-test остаётся за интегратором.
